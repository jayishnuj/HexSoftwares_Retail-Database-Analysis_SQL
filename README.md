# HexSoftwares_Retail-Database-Analysis_SQL
End-to-end MySQL analysis of customer shopping trends and sales performance. Features full database lifecycle implementation, missing value audits, data standardization, and complex EDA using window functions to uncover revenue drivers, demographic patterns, and seasonal preferences across 3,900 customer records.

# Data Source 
https://www.kaggle.com/datasets/iamsouravbanerjee/customer-shopping-trends-dataset
